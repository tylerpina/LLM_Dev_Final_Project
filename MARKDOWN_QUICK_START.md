## Example Response

```markdown
**Key AI Developments**

### Machine Learning
- **Deep learning models** achieving breakthroughs
- Neural networks with unprecedented accuracy

- **GPT-4** and advanced language models

```

## Markdown Elements Supported

| Markdown | Renders As | Style |
|----------|-----------|-------|
| `**text**` | **bold** | Green, emphasized |
| `*text*` | *italic* | Purple, italic |
| `` `code` `` | `code` | Orange, monospace |
| `## Heading` | Large heading | Green with underline |
| `### Subheading` | Section heading | Blue |
| `- item` | • Bullet point | Blue marker |
| `1. item` | 1. Numbered item | Green number |

5. **Default** - Balanced markdown usage
